# When a trial registry outsources its own search

**A WHO ICTRP primary registry serves a search interface that never queries its own database — and fails in ways the person searching cannot see.**

> [!IMPORTANT]
> **Finding.** The public search of ReBEC (`ensaiosclinicos.gov.br`) is a Google Custom Search over
> the website's pages, executed in the visitor's browser — not a query against the registry's 9,629
> records. The defects below are not three independent faults: **(2)** and **(3)** are what that
> single decision produces, and **(1)** is where it meets a separate certificate configuration. All
> were measured on **2026-08-25 (UTC)**:
> **(1)** the search box on the registry's own home page sends the visitor to a hostname the site's
> TLS certificate does not cover, so in current Chrome the search ends on a security interstitial;
> **(2)** the served response does not vary with the query string — six different terms returned
> HTTP 200 with a single byte-identical body of **69,877 bytes**, so every client that does not run
> JavaScript, **web archives included**, receives a search page that never filters;
> **(3)** for `dengue` the database holds **17** trials and the public search surfaces **14**
> (**recall 14/17**), two of the omissions being attributable index failures.
> Internet Archive captures place defect 2 on **2025-09-23**, **11 months** before our measurement —
> two measured points, not a continuous series.

## What this contributes

1. **A measurement nobody had made.** Registry practice has been studied for adherence and
   completeness. This asks a different question — *does the registry's own search return what its
   database holds?* — and answers it with numbers rather than impression.
2. **A protocol that transfers.** Every measurement pairs a term of interest with a **positive
   control**, and tests whether the response body is **identical across different queries**. Two
   cheap arms that together separate "there is nothing" from "the search did not run". The same
   protocol runs against any registry.
3. **A finding built to expire.** The instruments exit non-zero the day the search starts filtering.
   If ReBEC repairs this, the repair — not this report — becomes the outcome of record.

## What is and isn't claimed

**Claimed.** Three observable properties of a public system on a stated date, each measured by a
released instrument, most by two independent routes — and subordinate to one decision, not three
independent faults.

**Not claimed.** No intent, negligence or fault. Not that ReBEC's *records* are incomplete — the
database answered every query put to it. Not that the search is unusable: on the canonical host, in
a browser, it works. Not that the search never worked — the start date is unrecoverable. Not any
claim about by which route people reach ReBEC's records: the WHO ICTRP portal carries the same
records and was not measured. Defect 1 is
not generalised beyond current Chrome, and the report does **not** determine which of two mechanisms
performs the `http`→`https` upgrade; that attribution is left open, in the direction that makes the
claim conservative.

**Frozen.** The captures under `data/raw/` and the sealed JSONs under `output/` are evidence, not
functions. See [REPRODUCIBILITY.md](REPRODUCIBILITY.md) for the two-seals contract.

**One term.** Recall was measured for `dengue` (17 records). It does not scale by this route: the
search element returns at most about a hundred results. The strong number comes from a small case.

## Integrity

```bash
python scripts/verify_chain.py     # exit 0 = intact, exit 1 = a sealed byte changed
```

```text
artifact_root = f8cfa7b1014571c1b6dd4dfedd1c7e1d0a5d15bba697e2ed261386faf581ba04
```

A SHA-256 Merkle-per-stage left-fold chain over code, raw captures, sealed results, figures and
paper. The root is environment-independent, so any reviewer on any machine recomputes the same
value. The figures are folded **into** the root — they are pure-stdlib SVG with no plotting library,
so they regenerate byte-identically, and [a test asserts it](tests/test_determinism.py).
